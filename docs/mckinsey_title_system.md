# McKinsey 結論型標題系統完整指南

## 🎯 核心理念

> "標題不是告訴讀者『這一頁講什麼』，而是告訴讀者『這一頁的結論是什麼』"
> 
> —— McKinsey & Company 簡報設計原則

---

## 📋 標題公式系統

### 公式 1：數據驅動型（最常用）⭐
```
[主題] + [關鍵數據] + [趨勢/變化]

範例：
✅ "台灣電商市場年增 25%，行動商務成長最快"
✅ "客戶滿意度提升至 92%，創三年新高"
✅ "營運成本下降 18%，數位轉型初見成效"

❌ 錯誤示範：
- "市場規模分析" （主題型，沒有結論）
- "客戶滿意度調查" （過程型，沒有發現）
- "成本結構報告" （描述型，沒有洞察）
```

### 公式 2：洞察驅動型
```
[現象] + [原因] + [影響]

範例：
✅ "疫後復甦推動需求爆發，高階健檢占比升至 35%"
✅ "AI 自動化減少人力需求，技能升級成為關鍵"
✅ "供應鏈中斷加劇競爭，本土廠商迎來機會"

❌ 錯誤示範：
- "疫後市場變化" （沒有具體結論）
- "AI 對就業的影響" （太寬泛，沒有量化）
- "供應鏈挑戰" （只提問題，沒有洞察）
```

### 公式 3：對比驅動型
```
[比較對象] + [關鍵差異] + [意義]

範例：
✅ "競爭對手已投入 5 億研發，我們面臨技術落後風險"
✅ "新方案成本降低 40%，卻保持同等品質"
✅ "亞洲市場增速超越歐美，是未來十年重點"

❌ 錯誤示範：
- "競爭對手比較" （沒有具體發現）
- "新舊方案對比" （沒有結論）
- "各區域市場分析" （沒有優先級判斷）
```

### 公式 4：預測驅動型
```
[當前狀況] + [未來趨勢] + [行動意義]

範例：
✅ "預計 2025 年市場達 1,000 億，現在是進入最佳時機"
✅ "三年內需求將翻倍，產能擴充刻不容緩"
✅ "若不改變，預計兩年內損失 20% 市場份額"

❌ 錯誤示範：
- "未來市場預測" （沒有具體數字和結論）
- "產能規劃" （沒有急迫性）
- "風險分析" （沒有量化影響）
```

### 公式 5：策略驅動型
```
[核心策略] + [差異化優勢] + [預期成果]

範例：
✅ "聚焦高端市場，以技術創新打造差異化，預計毛利率提升 15%"
✅ "採用訂閱制模式，穩定現金流並提高客戶終身價值"
✅ "三大戰略支柱：產品創新、渠道擴張、品牌升級"

❌ 錯誤示範：
- "市場策略" （沒有具體內容）
- "商業模式" （沒有差異化說明）
- "未來規劃" （沒有預期成果）
```

## 🎯 不同頁面類型的標題策略

### 1. 執行摘要頁
**目標**：60 秒內傳達核心結論

**標題公式**：
```
[最重要的結論] + [為什麼重要] + [下一步]

範例：
✅ "三大發現：市場爆發、競爭加劇、策略轉型迫在眉睫"
✅ "核心結論：立即進入市場，預計三年 ROI 達 200%"
```

**內容結構（SCQA）**：
- **S (Situation)**：背景情境
- **C (Complication)**：出現的衝突/問題
- **Q (Question)**：關鍵問題
- **A (Answer)**：我們的答案/建議

### 2. 市場/數據分析頁
**目標**：用數據說服讀者

**標題公式**：
```
[市場主體] + [關鍵數據] + [趨勢方向]

範例：
✅ "台灣健檢市場達 700 億，年增 7% 創十年新高"
✅ "疫後復甦推動需求爆發，2024 年預計突破 800 億"
```

**關鍵要素**：
- 必須包含具體數字（金額、百分比、倍數）
- 必須說明趨勢（增長/下降、創新高/新低）
- 必須有時間框架（年度、季度、月度）

### 3. 趨勢/洞察分析頁
**目標**：解釋「為什麼」和「So What」

**標題公式**：
```
[核心趨勢] + [驅動因素] + [影響]

範例：
✅ "三大趨勢重塑市場：預防醫療、精準健康、個人化服務"
✅ "消費升級推動高階化，高端健檢占比提升至 35%"
```

**內容結構**：
- 趨勢描述 + 數據支持
- 驅動因素分析（為什麼發生）
- 影響說明（So What - 對我們的意義）

### 4. 競爭分析頁
**目標**：說明競爭態勢和我們的機會

**標題公式**：
```
[競爭格局] + [關鍵發現] + [對我們的意義]

範例：
✅ "傳統醫院佔據 70% 市場，技術創新創造突破機會"
✅ "競爭對手已投入 5 億研發，我們面臨技術落後風險"
```

**內容結構**：
- 市場份額分佈
- 主要玩家優劣勢
- 競爭空白點 / 我們的機會

### 5. 戰略建議頁
**目標**：提供可執行的行動方案

**標題公式**：
```
[核心策略] + [如何執行] + [預期成果]

範例：
✅ "聚焦高端市場，以 AI 診斷打造差異化，預計毛利率 45%"
✅ "三階段進入策略：試點 → 擴張 → 規模化，預計 18 個月達損益平衡"
```

**內容結構**：
- 策略選擇（為什麼選這個）
- 執行路徑（怎麼做）
- 預期成果（達成什麼）

### 6. 財務預測頁
**目標**：用數字證明可行性

**標題公式**：
```
[財務指標] + [關鍵數字] + [投資回報]

範例：
✅ "預計三年營收達 10 億，ROI 200%，投資回收期 18 個月"
✅ "初期投資 3,000 萬，預計五年累計獲利 1.2 億"
```

**內容結構**：
- 收入模型（怎麼賺錢）
- 成本結構（花多少錢）
- 投資回報（值不值得）

### 7. 風險評估頁
**目標**：識別風險並提出緩解方案

**標題公式**：
```
[主要風險] + [影響程度] + [緩解策略]

範例：
✅ "三大風險：法規變動、技術落後、市場競爭，均有緩解方案"
✅ "最大風險為資金缺口，建議分階段募資降低壓力"
```

**內容結構**：
- 風險識別（有哪些風險）
- 影響評估（嚴重程度）
- 緩解策略（怎麼應對）

### 8. 實施計畫頁
**目標**：提供清晰的執行路徑

**標題公式**：
```
[時間軸] + [關鍵里程碑] + [資源需求]

範例：
✅ "18 個月實施路徑：6 個月試點、12 個月擴張，需投入 50 人團隊"
✅ "Q1-Q4 四階段計畫，每階段設定明確交付成果"
```

**內容結構**：
- 時間軸（什麼時候做）
- 里程碑（達成什麼）
- 資源配置（需要什麼）

## 🚨 標題撰寫的常見錯誤

### 錯誤 1：主題型標題（最常見）❌

**錯誤示範**：
- "市場分析"
- "競爭態勢"
- "財務預測"
- "實施計畫"

**問題**：
- 只說「這頁講什麼」，沒有傳達結論
- 讀者需要看完內容才知道重點
- 無法獨立傳達價值

**修正方法**：
問自己：「如果用戶只看標題，他學到了什麼？」
如果答案是「不知道」，就需要重寫。

---

### 錯誤 2：過於冗長 ❌

**錯誤示範**：
- "基於過去五年的市場數據分析，我們發現台灣健康檢查市場在疫情後出現顯著復甦跡象，特別是高階健檢服務的需求大幅增長，佔比已從 2020 年的 25% 提升至 2024 年的 35%"

**問題**：
- 資訊過載，失去焦點
- 讀者無法快速抓到重點
- 視覺上不美觀

**修正方法**：
提煉核心訊息，控制在 15-20 字中文（或 10-15 個英文詞）。

**修正後**：
✅ "疫後復甦推動需求爆發，高階健檢占比升至 35%"

---

### 錯誤 3：缺乏量化數據 ❌

**錯誤示範**：
- "市場增長快速"
- "競爭日益激烈"
- "成本大幅下降"

**問題**：
- 「快速」、「激烈」、「大幅」都是主觀描述
- 缺乏說服力
- 讀者無法判斷程度

**修正方法**：
用具體數字替代形容詞。

**修正後**：
✅ "市場年增 25%，創五年新高"
✅ "前五大廠商佔據 80% 市場，新進者空間有限"
✅ "自動化使成本下降 18%"

---

### 錯誤 4：只陳述問題，不提結論 ❌

**錯誤示範**：
- "現有系統面臨三大挑戰"
- "市場存在五個主要趨勢"
- "競爭對手的策略分析"

**問題**：
- 只提出問題，沒有回答「So What」
- 讀者不知道應該採取什麼行動
- 缺乏明確的方向指引

**修正方法**：
加上結論和影響。

**修正後**：
✅ "現有系統老舊，維護成本年增 30%，數位轉型刻不容緩"
✅ "五大趨勢重塑市場，預防醫療和精準健康是未來重點"
✅ "競爭對手已完成雲端轉型，我們面臨技術落後風險"

---

### 錯誤 5：使用行話和專業術語 ❌

**錯誤示範**：
- "CAGR 達 15%，TAM 約 700 億"
- "採用 Agile 方法論，實施 DevOps 流程"
- "利用 AI/ML 技術優化 UX"

**問題**：
- 不是所有讀者都理解縮寫
- 增加認知負擔
- 可能造成誤解

**修正方法**：
用簡單語言解釋，或在首次出現時定義。

**修正後**：
✅ "市場年複合增長率 15%，總規模約 700 億"
✅ "採用敏捷開發，加速產品迭代速度提升 40%"
✅ "AI 技術優化使用體驗，客戶滿意度提升 25%"

## 🎯 標題撰寫檢查清單

生成每個標題後，執行以下檢查：

### 必須符合的 5 個標準：
- [ ] **結論性** - 傳達發現或結論（非主題或過程）
- [ ] **量化性** - 包含具體數字或百分比
- [ ] **完整性** - 獨立閱讀也能理解（不依賴內文）
- [ ] **簡潔性** - 15-20 字中文或 10-15 詞英文
- [ ] **價值性** - 回答「So What」（為什麼重要）

### 加分項：
- [ ] 使用「創新高/新低」等強調詞
- [ ] 包含趨勢方向（增長/下降/持平）
- [ ] 說明時間框架（年度/季度）
- [ ] 點出行動意義（機會/風險/建議）

## 📝 標題撰寫工作流程

### Step 1: 確定頁面核心訊息
問自己：
- 這一頁最重要的發現是什麼？
- 如果只能說一句話，我會說什麼？
- 這個發現對決策有什麼影響？

### Step 2: 收集關鍵數據
- 最重要的數字是什麼？
- 趨勢是什麼？（增長/下降/變化）
- 有沒有對比數據？（同比/環比/目標）

### Step 3: 套用公式
根據頁面類型選擇合適的公式：
- 數據頁 → 數據驅動型
- 分析頁 → 洞察驅動型
- 對比頁 → 對比驅動型
- 預測頁 → 預測驅動型
- 建議頁 → 策略驅動型

### Step 4: 精簡語言
- 刪除冗余詞彙（「的」、「了」、「非常」）
- 用數字替代形容詞
- 合併同義表達

### Step 5: 驗證品質
用檢查清單確認 5 個必須標準。

## 🎓 進階技巧

### 技巧 1：標題分層
如果資訊太多無法放入一行，使用「主標題 + 副標題」：

**主標題**（36pt）：
"台灣健檢市場達 700 億，年增 7% 創十年新高"

**副標題**（24pt，灰色）：
"疫後復甦推動需求爆發，高階健檢成長最快"

---

### 技巧 2：數字突出
關鍵數字用不同顏色或字號強調：

**標題**：
台灣健檢市場達 <span style="color: #FF6B35; font-size: 48pt;">700 億</span>，年增 7% 創十年新高

---

### 技巧 3：反問句引起注意
在某些情境下，用問句可以增加互動性：

**傳統方式**：
"現有系統老舊，維護成本年增 30%"

**反問方式**：
"為什麼維護成本年增 30%？系統老舊是主因"

（適用於問題診斷頁）

---

### 技巧 4：對比強調
用對比突出關鍵發現：

"競爭對手投入 5 億研發 vs. 我們僅 5,000 萬，技術落後風險迫在眉睫"

## 🔄 持續改進

### 學習機制
- 收集用戶對標題的反饋（太長/太短/不清楚）
- 分析哪些標題風格最受歡迎
- 記錄成功案例的標題模式

### A/B 測試
對於重要簡報，可以準備兩種標題風格讓用戶選擇：

**版本 A（數據驅動）**：
"台灣健檢市場達 700 億，年增 7% 創十年新高"

**版本 B（洞察驅動）**：
"疫後復甦推動需求爆發，健檢市場進入黃金期"
