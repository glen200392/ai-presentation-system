## 📊 改進摘要

### 問題診斷

**舊流程的根本問題**：
```
用戶請求 → 立即生成 → 發現不符需求 → 多輪修改 → 用戶挫折
   ↓          ↓            ↓              ↓          ↓
 模糊需求   假設場景    品質不符      浪費時間    信任下降
```

**後果**：
- 😤 用戶挫折：「為什麼不一開始就問清楚？」
- ⏰ 時間浪費：2小時變成4小時（反覆修改）
- 📉 信任下降：「AI不夠專業」
- 💸 成本增加：重複生成消耗資源

### 解決方案

**新流程（McKinsey/BCG 專業標準）**：
```
用戶請求 → 需求澄清 → 大綱確認 → 一次生成 → 高滿意度
   ↓          ↓          ↓          ↓          ↓
 明確需求   釐清參數   視覺預覽   職場品質   專業體驗
```

**效益**：
| 指標 | 舊流程 | 新流程 | 改善 |
|------|--------|--------|------|
| 需求確認 | 0分鐘 | 5分鐘 | +5分鐘投資 |
| 反覆修改 | 90-120分鐘 | 30分鐘 | **節省60-90分鐘** ⭐ |
| 首次滿意度 | 40% | 80%+ | **+100%** ⭐ |
| 總時間 | 150分鐘 | 65分鐘 | **節省85分鐘** ⭐ |

**投資5分鐘釐清需求，節省85分鐘修改時間**

## 🔄 新工作流程設計

### 第一階段：需求澄清（MANDATORY - 強制執行）

當用戶提出簡報需求時，**必須先執行需求澄清**，不可跳過直接生成。

#### 使用工具
```python
ask_user_choice(
    message="為了確保一次做對，請協助回答以下問題：",
    questions=[...]
)
```

#### 五個標準問題

**Q1. 聽眾定位**（單選）
- 投資人/創投（追求ROI、市場潛力、增長故事）
- 公司高階管理層（戰略決策、資源配置、風險評估）
- 業務團隊/客戶（商務開發、價值主張、解決方案）
- 內部團隊（知識分享、教育訓練、協作對齊）
- 學術/研究機構（嚴謹論證、方法論、文獻支持）

**Q2. 使用目的**（單選）
- 融資提案（需強調商機、增長潛力、投資回報）
- 戰略規劃（需深度分析、競爭態勢、路線圖）
- 商務開發（需客戶痛點、差異化、成功案例）
- 市場教育（需產業趨勢、數據支持、洞察分析）
- 內部報告（需進度追蹤、問題診斷、行動計畫）
- 學術發表（需研究方法、數據驗證、理論框架）

**Q3. 品質等級**（單選）
- 快速草稿級（30分鐘，60%品質，內部討論用，基礎排版）
- 業務實用級（1小時，75%品質，日常工作用，標準視覺）
- **職場頂級級**（2-3小時，85%品質，對外正式簡報，McKinsey排版標準）⭐ 推薦
- 諮詢公司級（4-6小時，95%品質，McKinsey完整標準，含SWOT/五力/戰略矩陣）

**Q4. 特殊內容需求**（多選）
- 執行摘要（1頁，60秒快速決策，SCQA架構）
- 競爭分析（五力分析/競爭矩陣/定位圖）
- SWOT分析（四象限+戰略建議）
- 財務預測（收入模型/成本結構/ROI分析）
- 戰略建議（進入策略/差異化/路線圖）
- 風險評估（風險矩陣/緩解方案）
- 實施計畫（時間軸/里程碑/資源配置）

**Q5. 視覺風格偏好**（單選）
- 簡約現代（扁平化、大留白、單一焦點）
- 商務正式（McKinsey/BCG風格、數據為王、結論導向）⭐ 推薦職場頂級
- 科技前衛（漸層色、未來感、動態元素）
- 視覺衝擊（大字標題、強對比、最小文字）
- 學術專業（保守配色、詳細標註、文獻支持）

### 第三階段：簡報生成（僅在批准後執行）

按照確認的規格執行生成，包含：

#### A. McKinsey 標題系統（CRITICAL）

**絕對禁止使用主題型標題**：
- ❌ "台灣健康檢查市場概況"
- ❌ "市場規模分析"
- ❌ "競爭態勢"

**必須使用結論型標題**：
- ✅ "台灣健檢市場達700億，年增7%創十年新高"
- ✅ "疫後復甦推動需求爆發，高階健檢占比提升至35%"
- ✅ "三大趨勢重塑市場：預防醫療、精準健康、個人化服務"

**標題撰寫公式**：
```
[核心發現] + [關鍵數據/趨勢] + [影響/意義]
```

#### B. 每頁必備結構

```
┌─────────────────────────────┐
│ [結論型標題 - 36pt]          │ ← 傳達關鍵訊息
├─────────────────────────────┤
│ [主要內容]                   │
│ - 視覺化數據（圖表/大數字）   │ ← 證據支持
│ - 簡潔文字說明               │
├─────────────────────────────┤
│ 💡 關鍵洞察：                │ ← So What
│ • [為什麼重要]               │
│ • [對決策的影響]             │
└─────────────────────────────┘
```

#### C. 視覺設計標準（職場頂級級+）

**配色系統**：
```python

**字體層級**：
```

layout = {

## ⚠️ 常見錯誤防範

### 絕對禁止的行為

1. ❌ **跳過需求澄清直接生成**
   - 後果：不符需求，需大量返工
   - 正確：必須先執行第一階段需求澄清
   
2. ❌ **使用主題型標題**
   - 錯誤：「市場分析」
   - 正確：「市場年增7%，創十年新高」
   
3. ❌ **缺少「So What」洞察**
   - 錯誤：只展示數據圖表
   - 正確：圖表 + "這意味著..."
   
4. ❌ **過度保守的排版**
   - 錯誤：1.0"邊距，導致內容擁擠
   - 正確：0.75"邊距，視覺舒適
   
5. ❌ **缺少視覺焦點**
   - 錯誤：所有元素同等大小
   - 正確：關鍵數字56pt突出
