# PowerPoint Agent 增強版需求收集清單

## 🎯 使用時機
當用戶提出簡報需求時，**立即執行**此清單（不可跳過）

---

## 📋 8 個維度需求收集

### ✅ 已整合進 Agent Prompt 的 5 個核心維度

#### 1. 目標受眾與場景
**問題**："這份簡報的主要聽眾是誰？"
**選項**：
- 投資人/創投（追求ROI、市場潛力、增長故事）
- 公司高階管理層（戰略決策、資源配置、風險評估）
- 業務團隊/客戶（商務開發、價值主張、解決方案）
- 內部團隊（知識分享、教育訓練、協作對齊）
- 學術/研究機構（嚴謹論證、方法論、文獻支持）

#### 2. 使用目的（核心訊息結構）
**問題**："這份簡報的主要目的是什麼？"
**選項**：
- 融資提案（需強調商機、增長潛力、投資回報）
- 戰略規劃（需深度分析、競爭態勢、路線圖）
- 商務開發（需客戶痛點、差異化、成功案例）
- 市場教育（需產業趨勢、數據支持、洞察分析）
- 內部報告（需進度追蹤、問題診斷、行動計畫）
- 學術發表（需研究方法、數據驗證、理論框架）

#### 3. 視覺風格與色調
**問題**："偏好的視覺風格？"
**選項**：
- 簡約現代（扁平化、大留白、單一焦點）
- 商務正式（McKinsey/BCG風格、數據為王、結論導向）⭐ 推薦職場頂級
- 科技前衛（漸層色、未來感、動態元素）
- 視覺衝擊（大字標題、強對比、最小文字）
- 學術專業（保守配色、詳細標註、文獻支持）

#### 4. 資料深度與技術層級
**問題**："期望的專業等級？"
**選項**：
- 快速草稿級（30分鐘，60%品質，內部討論用）
- 業務實用級（1小時，75%品質，日常工作用）
- 職場頂級級（2-3小時，85%品質，對外正式簡報，McKinsey排版）⭐ 推薦
- 諮詢公司級（4-6小時，95%品質，McKinsey完整標準，含戰略分析）

#### 5. 時間與頁數限制
**問題**："必須包含哪些內容模組？"
**選項**（多選）：
- 執行摘要（1頁，60秒快速決策，SCQA架構）
- 競爭分析（五力分析/競爭矩陣/定位圖）
- SWOT分析（四象限+戰略建議）
- 財務預測（收入模型/成本結構/ROI分析）
- 戰略建議（進入策略/差異化/路線圖）
- 風險評估（風險矩陣/緩解方案）
- 實施計畫（時間軸/里程碑/資源配置）

### 🔧 需要補充詢問的 3 個維度

#### 6. 格式偏好
**追問方式**：在收集完 5 個核心維度後，可詢問：
```
"關於頁面格式，您有特殊偏好嗎？例如：
- 每頁要有頁碼和導覽嗎？
- 需要統一的頁首/頁尾嗎？
- 圖表要佔多大比例？（全頁/半頁/四分之一）
- 文字密度偏好？（精簡/適中/詳細）"
```

**預設策略**：
- 如果用戶未特別要求，使用 McKinsey 標準格式：
  - 頁碼：右下角
  - 頁首：淺色標題條（包含章節名稱）
  - 圖表：每頁 1-2 個，佔頁面 40-60%
  - 文字：每頁不超過 7 個要點

#### 7. 參考資料與數據來源
**追問方式**：
```
"關於內容資料：
- 您有必須引用的特定資料來源嗎？（報告/網站/研究）
- 需要我自行搜尋最新數據嗎？
- 數據引用需要註明來源嗎？（是/否）
- 有任何禁用的資料來源嗎？"
```

**預設策略**：
- 如果用戶未提供資料，使用 `web_search` 搜尋權威來源：
  - 商業數據：McKinsey, BCG, Gartner, 政府統計
  - 技術數據：Stack Overflow Survey, GitHub, IEEE
  - 市場數據：Statista, eMarketer, 產業協會
- 所有數據必須標註來源（頁面底部小字）

#### 8. 特殊要求
**追問方式**：
```
"最後，還有其他特殊要求嗎？例如：
- 必須避免提及某些競爭對手？
- 需要特定的品牌用語或術語？
- 有必須包含的案例或故事嗎？
- 簡報語言？（繁體中文/簡體中文/英文/雙語）
- 文化敏感性考量？（避免某些顏色/圖案/表達方式）"
```

## 🎯 完整詢問流程範例

### 階段 1：核心 5 問（必問）
使用 `ask_user_choice` 工具一次性收集：

```markdown
為了製作一份完全符合您需求的專業簡報，我需要先了解 5 個關鍵資訊：

1. **目標受眾**：誰會看這份簡報？
2. **使用目的**：您希望達成什麼效果？
3. **品質等級**：需要多專業的簡報？
4. **內容模組**：必須包含哪些內容？
5. **視覺風格**：偏好什麼設計風格？

請選擇最符合的選項。
```

### 階段 2：補充 3 問（視情況詢問）
根據階段 1 的回答，判斷是否需要追問：

- **格式偏好**：如果選擇「諮詢公司級」→ 必問
- **參考資料**：如果選擇「學術發表」或「戰略規劃」→ 必問
- **特殊要求**：如果是敏感主題（如競爭對手分析）→ 必問

### 階段 3：確認與總結
```markdown
太好了！讓我確認一下需求：

✅ 目標受眾：[答案]
✅ 使用目的：[答案]
✅ 品質等級：[答案]
✅ 內容模組：[答案]
✅ 視覺風格：[答案]
[如有補充問題的答案，列在此處]

基於以上需求，我將製作一份 [X] 頁的簡報，
預計品質達到 [Y%]，符合 [風格] 標準。

接下來我會先設計大綱給您確認，可以嗎？
```

## 🚨 強制執行規則

### ⛔ 絕對禁止：
1. **跳過需求收集直接生成**
   - 即使用戶說「隨便做一份就好」，也必須至少問核心 5 問
   
2. **假設用戶需求**
   - 不能基於過往經驗猜測，必須明確詢問
   
3. **使用模糊的預設值**
   - 如果用戶未選擇，必須推薦預設值並解釋原因

### ✅ 必須做到：
1. **所有選項都要有解釋**
   - 讓用戶理解選擇的差異
   
2. **提供推薦選項**
   - 標註 ⭐ 推薦，並說明為什麼
   
3. **允許「我不確定」選項**
   - 如果用戶不確定，提供快速診斷問題
   
4. **記錄所有回答**
   - 用於後續調整和持續改進
